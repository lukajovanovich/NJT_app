# Frontend (Angular)

Angular 20 klijent za aplikaciju za upravljanje projektima. Opis celog projekta i uputstvo za pokretanje su u [glavnom README-u](../../README.md).

## Pokretanje

```bash
npm install
npm start
```

Aplikacija radi na `http://localhost:4200` i očekuje backend na `http://localhost:8080` (podešava se u `src/app/app.constants.ts`).

## Build

```bash
npm run build
```

Rezultat se nalazi u `dist/`.
